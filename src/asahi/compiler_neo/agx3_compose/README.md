# AGX3 generic instruction encoder

`agx3_compose.c` is one table-driven encoder for every form of both AGX3
encodings. `agx3b_tables.c` / `agx3c_tables.c` are generated by
`research/gpu/isa-re/gen-x/packgen/packgen.py` from Apple's own llvm::AGX3
encoder tables (recovered into `agx3{b,c}_fields_composed.json`). Do not edit
the tables by hand; regenerate them.

The consumer supplies Apple's anonymous field values (`fields[160]`); the
encoder gates the form on its predicates, selects each choice group, and
deposits every fixed bit and field under a shared written-bit shadow, failing
closed on any contradiction, unconsumed nonzero field, or over-wide value.

Validated in-tree: `test/test-agx3-compose-corpus.c` replays 1,494 real
G16G/G17S corpus instructions (decoded by the Python composer) and the C
encoder reproduces every one byte-exactly.
